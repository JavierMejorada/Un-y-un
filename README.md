INVITACIÓN YUNUEN — XV AÑOS (TEMA LONDRES)

Todos los archivos van juntos en la carpeta principal (sin subcarpetas),
tanto en GitHub como en Netlify. Abre index.html para probar.

Archivos:
- index.html ........................ la invitación
- londres-cabina-bigben.webp ........ Big Ben + cabina (PNG/WebP transparente) de la portada
- londres-portada.webp, westminster-rosa.webp ... fotos de las secciones
- icono-*.png, skyline-londres-lineas.png ... iconos PNG de Londres (Big Ben, cabina,
  bus, London Eye, Tower Bridge, corona, paraguas, taxi, destello)
- musica-original.mp3 ............... música instrumental

Portada: las letras "LONDON" se mueven solas, reaccionan al dedo/cursor y se deslizan al hacer scroll.
